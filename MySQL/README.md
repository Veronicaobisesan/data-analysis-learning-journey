# MySQL Learning and Practice

## Introduction

This folder contains my MySQL learning exercises and practical assignments. It documents my progress in learning SQL and practising database management using MySQL.

## Topics Covered

- Creating tables
- Adding columns
- Deleting columns
- Modifying columns
- Renaming columns
- Inserting records using `INSERT INTO`
- Adding constraints:
  - Primary keys
  - Foreign keys
- Dropping primary key constraints
- Creating indexes
- Creating unique indexes
- Dropping indexes
- Filtering data using IS NULL and IS NOT NULL
- Using logical operators: AND, OR, and NOT
- Filtering data within a range using BETWEEN
- Filtering data based on multiple values using IN
- Limiting query results using LIMIT

- Created tables using SQL.
