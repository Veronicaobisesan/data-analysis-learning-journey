- ### String Functions, Numeric Functions and Aggregate Functions
- `CHAR_LENGTH()` – Counts the number of characters in a text value.
- `CONCAT()` – Combines two or more text values.
- `LOWER()` – Converts text to lowercase.
- `UPPER()` – Converts text to uppercase.
- `TRIM()` – Removes leading and trailing spaces.
- `REPLACE()` – Replaces specified text with another value.
- `ABS()` – Returns the absolute value of a number.
- `SUM()` – Calculates the total of numerical values.
- `AVG()` – Calculates the average of numerical values.
- `MIN()` – Returns the smallest value.
- `MAX()` – Returns the largest value.
- `DIV` – Performs integer division and returns the whole-number quotient.
